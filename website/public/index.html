A FEW GOOD QUESTIONS

Before you jump.

Do I need AI to use J-Jump?

No. Name matching, visit history and navigation work locally. Choose off during the first-run setup. You can enable a semantic provider later with jjump setup.

Does it search my whole computer?

No. J-Jump only searches the folders you have visited since installing it. It starts empty. Visit a folder with cd once, then find it with j or ji.

Is it free?

J-Jump is free and open source under the MIT license. Optional cloud model providers may charge for API requests. Local Tev1 requires your own Ollama installation and a model download.

What if I already use the j command?

Choose another name when connecting your shell: jjump shell install --cmd jump. This gives you jump and jumpi.

What should I know about this beta?

J-Jump is still in its 0.0.x releases. Expect rough edges, and occasional upgrades that need a one-time settings or history fix. Run jjump doctor for guidance. Release binaries are unsigned; installers verify their SHA-256 checksums.
